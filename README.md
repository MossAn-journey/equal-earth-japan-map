# Equal Earth Japan Map

日本列島をイコールアース図法（Equal Earth）で見るための小さなWeb地図です。

## 特徴

- イコールアース図法 / メルカトル図法の切り替え
- 中央経線の変更
- 都道府県境・経緯線・ラベルの表示切り替え
- 日本全体、北海道、本州、四国、九州、沖縄・南西諸島、北方領土への表示範囲ジャンプ
- マウス・タッチによるパン、ズーム
- SVGによるブラウザ描画

## データ

初版では、国土地理院の「地球地図日本」を元にした `jpn-atlas` のTopoJSONを利用しています。国土地理院の現在の基盤地図情報そのものを同梱しているわけではありません。

基盤地図情報の海岸線・行政区画等を使った、より高精度な版への置き換えを想定しています。

## 技術

- HTML / CSS / JavaScript
- D3.js / d3-geo
- topojson-client
- GitHub Pagesで静的公開可能
